# Chocolate bar choice study (choice-based conjoint)

Synthetic choice-based-conjoint (CBC) data for a chocolate-bar study. 200
respondents each completed 8 choice tasks; in every task they chose one of 3
product alternatives. The data are in the long format expected by
`pyrsm.multivariate.cbc`: one row per alternative per task.

Generated by `scripts/generate_cbc_example.py` (deterministic, seed 1234) from a
known set of part-worths, so estimated utilities recover the data-generating
values.

| Variable    | Description |
|-------------|-------------|
| `resp`      | Respondent id |
| `choice_id` | Unique choice-task id (the grouping/"observation" id) |
| `alt`       | Alternative id within a task (1–3) |
| `brand`     | Brand: Hershey, Lindt, Godiva |
| `chocolate` | Type: Milk, Dark, White |
| `price`     | Price in $ (2.99, 3.99, 4.99) |
| `nuts`      | Contains nuts: No, Yes |
| `chosen`    | 1 if this alternative was chosen in the task, else 0 |

True part-worths used to simulate the data: brand (Hershey 0, Lindt 0.8, Godiva
1.3), type (Milk 0, Dark 0.5, White −0.4), price −0.9 per $, nuts (No 0, Yes
0.3).
